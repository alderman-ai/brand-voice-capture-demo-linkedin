# Honest limits

This repo is a snapshot of early working files, not a product. The rubric
says so in its own header, so this page does too. Its rule for weak spots is
"recorded, not hidden."

- **Directional, not validated.** The first version was built from about 20
  unique graded source posts. That is under the ~30 that the research
  literature treats as the minimum for this kind of work; the production
  target is about 100, with a separate set held back for checking.
- **"Great" rests on one data point.** In the second round, only one post
  was graded Great as written. The other Great examples are Alex's own
  rewrites, so the top grade is largely his voice by construction. Criteria
  that only decide Good versus Great are labelled "doctrine-supported;
  tier-separation unmeasured."
- **No consistency number.** There is no measure of how consistently Alex
  grades the same post twice, and the rubric forbids claiming one: the
  duplicate test was voided because the duplicates were recognisable.
- **The first notes mixed mechanics with personal taste.** Alex: "This first
  iteration blended too much of the mechanical with my individual taste. i've
  gotten better at finding that line since."
- **Not everything is here.** More refined versions of these files exist.
  The large quick-grade tables and Alex's full corpus of self-written posts
  are not published. Nor is the "post silhouette" vector, which he calls
  probably the biggest breakthrough; a small peek is in the summary page
  linked from the root README.
- **Some paths in the rubric don't exist here.** References like
  `Working/...` and `Deliverables/...` point to Alex's private workspace.
